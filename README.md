# 💰 Personal Finance Tracker

A simple and user-friendly Personal Finance Tracker built using **HTML, CSS, and JavaScript**. This application helps users manage their income, track expenses, monitor savings, and understand their spending habits through an organized dashboard.

## ✨ Features

- 💵 Track income and expenses
- 📊 View total balance
- 🧾 Add and manage transactions
- 📈 Monitor spending habits
- 💰 Track savings
- 🗂️ Categorize transactions
- 🎨 Clean and modern dashboard
- 📱 Responsive user interface

## 🛠️ Technologies Used

- **HTML5** – Application structure
- **CSS3** – Styling and responsive layout
- **JavaScript** – Transaction management and calculations

## 🚀 Getting Started

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Start tracking your income and expenses.
